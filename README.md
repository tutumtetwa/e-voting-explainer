# E-Voting Explained

A single-page explainer on **electronic and internet voting**, built as a presentation site.

**Live site:** https://tutumtetwa.github.io/e-voting-explainer/

## What it covers

- Definition and history of electronic and internet voting
- How e-voting has evolved
- Advantages and disadvantages
- Case studies of successes (Estonia, West Virginia, Switzerland) and failures (Iowa, Washington D.C., Norway)
- The way forward

It also has a built-in 10-minute presenter countdown timer with start and reset buttons.

## Tech

HTML, Bootstrap 5, SCSS, vanilla JavaScript, AOS scroll animations and Swiper. It is a static site with no build step: open `index.html` or serve the folder.

```bash
python3 -m http.server 8000   # then visit http://localhost:8000
```

Built for CS 345 (Computers & Society) by Tutu Mtetwa. Layout based on a BootstrapMade template.
